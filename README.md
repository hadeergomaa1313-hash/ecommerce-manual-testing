# E-commerce Manual Testing

A practical project to test the main features of an e-commerce website and document the results.

**Website:** [nopCommerce Demo](https://demo.nopcommerce.com/)

**Testing Type:** Manual Testing  
**Status:** In Progress

---

## 1. Project Goals

- Practice writing test cases.
- Test the main website features.
- Report bugs with clear reproduction steps.
- Compare actual and expected results.

## 2. Features to Test

| Feature | What I Will Check |
|---|---|
| Registration | Required fields and input validation |
| Login | Valid and invalid credentials |
| Product Search | Search results for different inputs |
| Product Details | Product information |
| Shopping Cart | Adding and removing products |
| Wishlist | Adding and removing products |
| Checkout | Steps required to place an order |

## 3. Testing Documents

I will add these documents as I progress:

- **Test Plan** — what I plan to test.
- **Test Cases** — steps and expected results.
- **Bug Reports** — defects I find and verify.
- **Regression Checklist** — features to retest.
- **Test Execution Report** — testing results.
